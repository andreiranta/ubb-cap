A prototype mobile app I wrote in 2024 to help me prepare for my UBB CS multiple-choice admission exam. It has past exams subjects and the answers. When I solved a subject, I could select the answer(s) for each problem and, at the end, the application would calculate the final grade using UBB's exam formula. That way I simulated exams in my bedroom using past subjects, which was very helpful when the real exam came.
